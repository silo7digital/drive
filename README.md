# The 2 Mile Pastor prototype

Open `index.html` in a browser. Keep the files and the `frames` directory together. The site works offline and requires no installation.

On desktop, scroll in either direction to scrub the drive. Use the bottom control to advance to the next sign. Click a roadside sign or use Menu to open a destination. Back to the road returns to the same point. On mobile and with reduced motion enabled, a still from the drive appears above direct navigation links.

The four signs are real links placed over frames from stock footage. Their positions, scale and perspective are manually approximated for the demo. Messages, ordering and giving are placeholder content.

Film by [Dimitri Baret on Pexels](https://www.pexels.com/video/point-of-view-of-a-car-driving-along-the-road-15330792/), under the [Pexels license](https://www.pexels.com/license/). Typography uses the device’s Georgia and Arial system fonts.
